# Portfolio site

Static bilingual portfolio prepared for GitHub Pages.

## Update content

Most routine updates happen in `assets/content.js`:

- name, title and portrait path;
- Russian and English CV copy;
- showreel and project video links;
- Color project titles and image lists;
- Software project titles and links;
- email and Telegram.

Place new images in `assets/images/` using simple Latin filenames, then add their paths to `assets/content.js`.

Supported video links: YouTube, Vimeo, direct MP4/WebM, or an external link.

## Local preview

Open through a local web server rather than double-clicking the HTML files. Any static server works.

## GitHub Pages

Publish the repository from the `main` branch and the repository root. Every push to `main` updates the live site automatically.
